# 専門調理師 共通問題・学習アプリ

専門調理師学科試験の共通問題を、年度・前後期ごとに○×形式で学習する非公式のWebアプリです。

## 使い方
1. [index.html](./index.html) をブラウザーで開きます（GitHub Pagesを設定すればWebでも利用できます）。
2. 「問題JSON」を手元の端末から選択してください。
3. 「年度・試験回別」「頻出テーマ別」「出題分野別」から選んで学習できます。
4. 正誤・復習・「覚えた」の履歴は、そのブラウザーのlocalStorageに保存されます。

### 問題データについて
公式過去問題の原文を含む240問データは、著作権等の扱いを確認するため **この公開リポジトリには含めていません**。配布済みの個人学習用JSONファイルを、ご自身の端末で取り込む設計です。JSONはGitHubには送信されません。

JSONは次の形式の配列です（これは架空の例です）。

```json
[{"year":"令和7年度","session":"前期","number":1,"question":"（問題文）","answer":"○","explanation":"（解説）"}]
```

頻出テーマの分類はキーワードに基づく簡易版です。以前のローカル版にある34テーマの厳密なグルーピングとは異なります。

## 公開
このリポジトリは公開設定です。GitHub Pagesを利用する場合は Settings → Pages → Deploy from a branch → main / (root) → Save の順で設定します。GitHub Pagesを設定しても、端末に取り込んだ問題JSONは公開されません。

## 注記
非公式学習アプリであり、試験実施団体とは関係ありません。問題・正解・解説は自身で確認のうえ学習してください。
